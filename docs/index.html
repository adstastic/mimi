mimidictation for macOS

Talk to your Mac. It types.

Local dictation for macOS. Leave the mic armed, say what you want, and the words land wherever your cursor is.

Any text fieldReady

Turn on ambient mode and wait, or hold the key and release.

Fully local

Speech becomes text on your Mac. No account, no upload, no telemetry. Recordings are discarded once they're transcribed.

Ambient mode

Nothing to hold. mimi starts when you start talking, stops when you pause. Enroll your voice once and it keeps only your speech — a call on speaker, a video, someone else in the room, none of it reaches your text.

Voiceprint filtering is still rough with overlapping voices. Prefer a key? Hold Right Command. Escape cancels either way.

Run agent sessions hands-free

Turn on send with Return and ambient mode becomes a loop: you speak, mimi inserts the text and hits Return, your agent runs. Answer the next prompt from across the room, hands nowhere near the keyboard.

Run it

git clone https://github.com/adimuk/mimi
cd mimi
scripts/run_app.sh

Grant microphone and accessibility permission when asked, then start talking.
